# 👋 Welkom op mijn Portfolio

Dit is mijn persoonlijke portfolio, gemaakt met **React** en **Bootstrap**.  
Hier kun je een overzicht vinden van mijn projecten, vaardigheden en contactinformatie.

- [React](https://reactjs.org/) – voor het bouwen van de UI-componenten.  
- [Bootstrap](https://getbootstrap.com/) – voor een snel en responsief ontwerp.  
- CSS – voor maatwerk stijlen en aanpassingen.
