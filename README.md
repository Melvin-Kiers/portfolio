# 👋 Welkom op mijn Portfolio

Dit is mijn persoonlijke portfolio, gemaakt met **React** en **Bootstrap**.  
Hier kun je een overzicht vinden van mijn projecten, vaardigheden en contactinformatie.

---

## 🌟 Functies

- **Responsief ontwerp:** Dankzij Bootstrap ziet de portfolio er goed uit op zowel desktop als mobiel.  
- **Projectoverzicht:** Bekijk al mijn persoonlijke en professionele projecten op één plek.  
- **Interactieve componenten:** Dynamische navigatie, kaarten, knoppen en andere React-componenten.  
- **Contactsectie:** Eenvoudig contact opnemen via een contactformulier of via sociale media.  

---

## 💻 Gebruikte Technologieën

- [React](https://reactjs.org/) – voor het bouwen van de UI-componenten.  
- [Bootstrap](https://getbootstrap.com/) – voor een snel en responsief ontwerp.  
- CSS – voor maatwerk stijlen en aanpassingen.
